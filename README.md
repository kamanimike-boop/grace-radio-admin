# Grace Radio Admin Panel v1

Mobile-friendly Supabase admin panel starter.

1. Open `index.html`.
2. Replace `PASTE_YOUR_PUBLISHABLE_KEY_HERE` with the Supabase publishable key.
3. Host the folder on an HTTPS static host.

Features: admin login, dashboard counts, weekly programs, podcast upload, private e-book upload, advertisements, notification records, orders, and radio settings.

Do not put a Supabase service-role/secret key in the browser. E-book payment verification and secure download authorization are intentionally reserved for the next stage.
